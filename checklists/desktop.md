# Desktop Domain Checklist
- [ ] Native menus: application menu bar follows OS conventions (File, Edit, View, Help order)
- [ ] Keyboard shortcuts: standard shortcuts work (Cmd/Ctrl+S, Z, C, V, Q), custom shortcuts documented
- [ ] Multi-monitor: window positioning respects display boundaries, remembers last position per monitor
- [ ] Auto-update: update mechanism configured, user notified before restart, rollback on failed update
- [ ] Installer/uninstaller: clean install and uninstall, no orphaned files, registry entries cleaned on Windows
- [ ] File associations: registered file types open in app, icons display in file explorer
- [ ] System tray: minimize-to-tray option, tray icon shows status, right-click context menu
- [ ] Crash reporting: unhandled exceptions captured with stack trace, user prompted to send report
