# Web Domain Checklist
- [ ] WCAG 2.1 AA compliance on all new/modified UI
- [ ] Responsive design tested at 320px, 768px, 1024px, 1440px breakpoints
- [ ] Core Web Vitals: LCP <2.5s, FID <100ms, CLS <0.1
- [ ] XSS prevention: all user input sanitized/escaped before rendering
- [ ] CSRF tokens on all state-changing forms
- [ ] Semantic HTML: proper heading hierarchy, landmark regions, alt text
- [ ] Keyboard navigation: all interactive elements focusable and operable
- [ ] Color contrast ratio ≥4.5:1 for normal text, ≥3:1 for large text
